# Sonic Heroes (Unity)

A fan-made recreation of Sonic Heroes built in Unity.

## Project Status

The project is currently playable and under active development.

### Features

- Team Sonic, Team Dark, Team Rose, Team Chaotix, and Last story gameplay
- Team switching
- Multiple playable stages
- Pause menu
- HUD
- Character abilities
- Audio system
- Updated lighting
- Unity 6.5 compatibility
- 2D and/or 3D Action Stages

## Known Issues

- Unity may display the following warning:
  ```
  Failed to create the agent because there is no valid NavMesh
  ```
  This warning is known and does not affect gameplay. The project functions correctly without a baked Unity NavMesh.

## Requirements

- Unity 6 (6000.x.x) or later

## Getting Started

1. Clone the repository.
2. Open it with Unity Hub.
3. Let Unity import all assets.
4. Open a stage scene.
5. Press **Play**.
